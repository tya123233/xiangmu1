## 🎨 CSS 实现策略

### 1. 坐标转换系统

```typescript
// Figma 原点坐标
const ORIGIN_X = 6971
const ORIGIN_Y = -2959

// 转换为相对坐标
const toRelative = (x: number, y: number) => ({
  left: x - ORIGIN_X,
  top: y - ORIGIN_Y,
})
```

### 2. 响应式比例计算

```css
/* 容器宽高比保持 */
padding-bottom: calc((23299 / 1440) * 100%); /* ≈ 1618% */

/* 元素位置百分比 */
left: calc((相对X / 1440) * 100%);
top: calc((相对Y / 23299) * 100%);
width: calc((宽度 / 1440) * 100%);
height: calc((高度 / 23299) * 100%);
```

### 3. 层级管理

```
Z-Index 层级:
- 0: 最底层背景 (1207:8)
- 1: 次级背景 (1187:124)
- 10: 所有图片元素
- 20: 粉色遮罩块
- 100: 右上角文字标注
```

## 💻 代码实现细节

### 核心组件结构

```typescript
interface TimelineElement {
  id: string                 // Figma 元素 ID
  type: 'image' | 'mask' | 'background'
  x: number                  // Figma 绝对 X 坐标
  y: number                  // Figma 绝对 Y 坐标
  width: number              // 宽度 (px)
  height: number             // 高度 (px)
  name?: string              // 元素名称
  src?: string               // 图片路径
  color?: string             // 颜色值
  opacity?: number           // 透明度
  zIndex?: number            // 层级
  borderRadius?: number      // 圆角 (px)
}
```

## 🎯 关键技术点

### 1. 绝对定位 + 百分比布局

✅ **优势**:
- 精确控制每个元素位置
- 完美还原 Figma 设计
- 自动响应式缩放

### 2. Padding-Bottom 技巧

```css
padding-bottom: ${(23299 / 1440) * 100}%
```

保持容器宽高比，内部使用绝对定位实现像素级精准布局。

### 3. 坐标系转换

Figma 使用绝对坐标系统，代码通过减去原点坐标转换为相对定位。

### 4. 性能优化

- 使用 CSS Transform 而非 top/left 做动画
- 合理使用 z-index 分层
- 图片懒加载（可选）
